# Architecture Decision Records

Use ADRs for consequential decisions that future agents need to understand rather than rediscover.

## Status values

- Proposed
- Accepted
- Superseded
- Deprecated

## Index

| ADR | Status | Decision |
|---|---|---|
| `0000-template.md` | Template | ADR format only |

When adding an ADR, use the next zero-padded number and add it to this table.
